# HKRBC Implementation Documentation

1. **Cap 41R - Insurance (Valuation and Capital) Rules**
   - Location: `docs/hkrbc/technical_specs/Cap_41R_Consolidated.pdf`

## Document Management Rules

1. All implementations must reference specific sections of Cap 41R
2. Code documentation should include:
   - Reference to relevant Cap 41R section numbers
   - Direct quotes of key rules where appropriate
   - Any interpretation or assumptions made
